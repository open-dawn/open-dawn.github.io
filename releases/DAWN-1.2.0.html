DAWN 1.2.0 introduces a new visual identity, refreshes how you create and manage workspaces, and adds automatic update checks with optional analytics.

Highlights

Redesigned DAWN

  • New app icon, typography, and colors across the app.
  • Redesigned sidebar, workspace details, Settings, About screen, and menu-bar interface.
  • The menu-bar icon changes when a workspace is active.

Workspace management

  • Contexts are now called workspaces throughout DAWN.
  • The workspace creation flow has redesigned steps for choosing a name and icon, adding apps, setting opening behavior, and reviewing the workspace.
  • Saved contexts migrate to workspaces when you upgrade.
  • If you use the command-line tool, update scripts that call dawncli context to use dawncli workspace. Run dawncli workspace --help to see the available commands.

Updates and analytics

  • DAWN can check for updates automatically. Installing an update still requires your action.
  • DAWN asks whether you want to share update-check analytics. If you opt in, update checks include a generated installation ID, the DAWN and macOS versions, and whether you checked manually or on a schedule. You can change your choice in Settings.

Requirements

  • Apple Silicon Mac
  • macOS 15.0 or later
  • Accessibility permission to manage apps and windows

Installation

New installation

  1. Open DAWN-1.2.0.dmg from the release assets.
  2. Drag DAWN into Applications, then open it from there.
  3. Grant Accessibility permission when prompted. If macOS asks for approval to run the DAWN background item, allow it.

Updating from DAWN 1.1.0

Install 1.2.0 through DAWN’s update interface when it’s offered, or replace the installed app using the new DMG. After DAWN relaunches, check that your saved workspaces are visible and the DAWN Agent is connected.

Optional command-line tool

Use the installation banner in DAWN’s Settings to install dawncli. macOS requires administrator approval to create the command at /usr/local/bin/dawncli.

Known limitations

  • DAWN supports Apple Silicon only.
  • New Instance may behave differently depending on the app.
  • If the background item is disabled, re-enable DAWN under System Settings → General → Login Items & Extensions to restore the agent connection.
  • Some dawncli commands require the DAWN Agent to be running and Accessibility permission to be granted.

Uninstallation

  1. Quit DAWN, then quit the DAWN Agent from its menu-bar menu.
  2. If you installed the optional CLI, remove the /usr/local/bin/dawncli symlink.
  3. If DAWN still appears under System Settings → General → Login Items & Extensions, disable its background item.
  4. Move DAWN from Applications to the Trash.
