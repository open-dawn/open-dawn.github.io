DAWN 1.0.0 is the first official release of DAWN, a native macOS workspace manager for organizing apps and windows into contexts.

Highlights

Context management

  • Create, edit, search, archive, and restore contexts.
  • Add applications using the picker or drag and drop.
  • Configure how applications open when a context is activated.
  • Protect selected applications from workspace transitions.

Workspace transitions

  • Switch between groups of applications and windows.
  • Restore application windows when activating a context.
  • Track the active context and its recent activity.
  • By default, applications outside the active context are hidden. They can optionally be quit through DAWN’s settings.

Menu bar agent

  • Switch contexts without opening the main DAWN window.
  • Create contexts directly from the menu bar.
  • View information about the active context.
  • The DAWN Agent remains available when the main application is closed.

Redesigned DAWN application

  • New sidebar and navigation experience.
  • Improved context creation and context-detail screens.
  • Integrated settings, accessibility permission status, and update availability.
  • New About screen with build and source information.

Secure updates

  • Signed updates delivered through Sparkle.
  • Manual update checks and update availability in the sidebar.
  • Download verification before installation.

Requirements

  • Apple Silicon Mac
  • macOS 26.0 or later
  • Accessibility permission for application and window management

Installation

  1. Download DAWN-1.0.0.dmg.
  2. Open the disk image.
  3. Drag DAWN into Applications.
  4. Launch DAWN from Applications.
  5. Grant Accessibility permission when prompted.
  6. Allow the DAWN background item if macOS requests approval.

Known limitations

  • Intel Macs are not supported.
  • The Open at login preference has been postponed to a future update.
  • The New Instance option may not work reliably with every application.
  • If the DAWN background item is disabled in System Settings, DAWN cannot connect to the agent. Re-enable it under System Settings → General → Login Items & Extensions.
  • Automatic recovery after manually quitting or terminating the DAWN Agent is limited. Signing out and back in may be required.

Uninstallation

  1. Quit DAWN.
  2. Quit the DAWN Agent from its menu-bar menu.
  3. Open System Settings → General → Login Items & Extensions and disable DAWN if it remains listed.
  4. Remove DAWN from Applications.
